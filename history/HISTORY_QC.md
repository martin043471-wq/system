# HISTORY_QC: проверка статьи перед публикацией

## 1. Таблица фактов (заполняется до черновика)

| Факт | Значение | Год и регион | Источник | Проверено |
|---|---|---|---|---|
| пример: цена хлеба | ... | ... | ... | да/нет |

Правило: в статью попадают только строки с отметкой «да».

## 2. Чек-лист достоверности

- Герой реальный и назван, либо статья помечена как реконструкция типичного дня.
- Все даты, имена, должности, цены сверены с таблицей фактов.
- Реплики взяты из источников и подписаны, выдуманных диалогов нет.
- Есть блок «Что известно, а что нет».
- Есть блок «Как мы это знаем» с названием источника.
- Нет слов «шокирующий», «никто не знал», «скрывали».
- Нет политических оценок современности.

## 3. Чек-лист текста

- Объём от 5 000 знаков (цель 6 500).
- 0 звёздочек, решёток, линий, маркеров списков.
- 0 длинных тире, 0 ASCII-кавычек, только «ёлочки».
- Нет штампов из HISTORY_CORE.md, раздел 5.
- Нет оборванных предложений и дублей абзацев.
- Абзацы разной длины, есть короткие переходы.

## 4. Скрипт автопроверки (Python)

```python
import re, sys
text = open(sys.argv[1], encoding='utf-8').read()
bad_marks = ['*', '#', '---', '\u2014', '"']
stamps = ['однако', 'безусловно', 'стоит отметить', 'важно понимать', 'если честно', 'после этого', 'в тот момент', 'шокирующ', 'никто не знал', 'скрывали', 'оказалось, что', 'на сегодняшний день']
print('знаков:', len(text))
for m in bad_marks:
    print(repr(m), text.count(m))
for s in stamps:
    if s in text.lower():
        print('штамп:', s)
paras = [p for p in text.split('\n') if p.strip()]
print('дубли абзацев:', len(paras) - len(set(paras)))
print('последний символ:', repr(text.strip()[-1]))
```

Фактическая проверка (даты, цены, имена) скриптом не заменяется и выполняется вручную по таблице фактов.
