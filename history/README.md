# history: система канала historyones

Отдельный контур для канала про историю XVIII–XIX века. Не смешивается с PETS (корневые файлы репозитория).

Файлы:
- HISTORY_CORE.md: мастер-правила формата «Один день, одна судьба».
- HISTORY_QC.md: таблица фактов, чек-листы и скрипт проверки.
- HISTORY_TOPICS.md: база тем и статус.
- HISTORY_JOURNAL.md: журнал публикаций.

Порядок работы: тема из HISTORY_TOPICS.md, сбор фактов по HISTORY_QC.md, черновик по HISTORY_CORE.md, проверка, утверждение владельцем, запись в журнал.
