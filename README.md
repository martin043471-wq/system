## 🚀 Как пользоваться — пошагово

### Сценарий "написать статью с телефона за 30 минут":

**Шаг 1 (1 мин).** Открой `dzen_temy_PETS_DATA_DRIVEN.md` → выбери тему (по CTR-цвету или по эмоции).

**Шаг 2 (3 мин).** Открой нейросеть (Claude / GPT). Прикрепи 7 файлов:
- `SUPER_PROMPT.md`
- `0_DZEN_FORMAT_TEMPLATE.md`
- `1_INSTRUKCIYA_PRO.md`
- `2_STIL_I_GOLOS_PRO.md`
- `3_FORMATY_I_STRUKTURA.md`
- `4_ISTOCHNIKI_I_FAKTY.md`
- `5_QC_AVTOPROVERKA.md`

**Шаг 3 (3 мин).** Вставь содержимое `SUPER_PROMPT.md` в чат. Заполни блоки `[ТЕМА]` и `[ЛИЧНЫЙ ЯКОРЬ]` (8–15 строк про твою жизнь с питомцем). Отправь.

**Шаг 4 (5–10 мин).** Получаешь готовую статью в Дзен-ready формате: заголовок + метки + 5 SEO-фраз + текст разбит на 8–14 блоков с подсказками куда тапнуть.

**Шаг 5 (10–15 мин на телефоне).** Открой студию Дзен в браузере или в приложении. Идёшь по блокам сверху вниз:
- Копируешь заголовок → вставляешь в поле «Заголовок».
- Копируешь содержимое каждого блока (между линиями `─────`) → вставляешь в редактор → применяешь форматирование из заголовка блока (Ж / К / цитата / подзаголовок).
- В конце копируешь метки → вставляешь в поле «Темы».

**Шаг 6 (1 мин).** Прикрепляешь обложку (если есть). Публикуешь.

## Главные правила системы (TL;DR)

- **Длина:** 5000–8000 знаков (целевой 6500).
- **От первого лица женщины 50+,** имеющей собаку.
- **Кавычки только ёлочки «»**. ASCII " и ' — бан.
- **Тире длинное —**. Дефис "-" только в составных словах.
- **35–40% диалогов** в личных статьях.
- **Без литературщины:** "сердце сжалось", "ком в горле" — запрещено.
- **Финал с надеждой,** не трагедия.
- **CTA в конце** — открытый вопрос.
