## 🚀 Быстрый запуск (1 файл вместо 7)

1. Выбери тему из **`dzen_temy_PETS_DATA_DRIVEN.md`** (100 тем с CTR-цветами).
2. При необходимости возьми 1 якорь из **`dzen_yakorya_lichnye.md`** (не прикрепляй файл целиком).
3. Открой Claude / ChatGPT, прикрепи **`SYSTEM_CORE.md`**, вставь `[ТЕМА]` и `[ЛИЧНЫЙ ЯКОРЬ]` и отправь.
4. Прогони полученный текст через Python-скрипт из **`5_QC_AVTOPROVERKA.md`**.
5. Скопируй блоки в студию Дзен с телефона и опубликуй.
